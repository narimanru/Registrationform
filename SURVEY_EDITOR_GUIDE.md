# Руководство по редактору опросника FASTWMS

## Обзор изменений

### 1. Обновлена структура опросника
- **Вопрос 4 "Главные задачи"**: Теперь поддерживает множественный выбор (можно выбрать несколько вариантов)
- **Вопрос 6 "Фулфилмент"**: Удален подвопрос про RBAC
- Добавлен новый тип поля `primaryGoals` (массив) вместо `primaryGoal` (строка)

### 2. Редактор опросника в админ-панели
Доступ: `/admin` → вкладка "Редактор опросника"

#### Функции редактора:
- **Просмотр всех вопросов**: Свернуть/развернуть каждый вопрос
- **Редактирование вопросов**: 
  - Изменить заголовок
  - Изменить описание
  - Изменить тип вопроса (один вариант/несколько/текст/подвопросы)
  - Добавить/удалить подсказку (tooltip)
- **Управление вариантами ответов**:
  - Добавить новый вариант
  - Удалить вариант
  - Редактировать значение, текст и описание варианта
- **Изменение порядка вопросов**: Кнопки "Переместить вверх/вниз"
- **Сохранение изменений**: Кнопка "Сохранить изменения"

## Как использовать

### 1. Доступ к редактору
1. Перейдите на `/admin`
2. Выберите вкладку "Редактор опросника"

### 2. Редактирование вопроса
1. Нажмите на вопрос, чтобы развернуть его
2. Нажмите кнопку "Редактировать" (иконка карандаша)
3. Измените нужные поля
4. Нажмите "Сохранить изменения" вверху страницы

### 3. Добавление варианта ответа
1. Разверните вопрос и включите режим редактирования
2. Нажмите "Добавить вариант"
3. Заполните поля нового варианта
4. Сохраните изменения

### 4. Изменение порядка вопросов
1. Используйте кнопки со стрелками вверх/вниз
2. Вопросы автоматически переупорядочатся
3. Сохраните изменения

## Примечания

- Изменения сохраняются в localStorage (для demo)
- В production версии нужно подключить API для сохранения на сервере
- Все изменения отображаются в реальном времени в опроснике
- Структура вопросов экспортируется в `SURVEY_QUESTIONS` константу

## Навигация

- `/signup` - Регистрация
- `/survey/intro` - Введение в опросник
- `/survey/step/:step` - Шаги опросника (1-7)
- `/survey/success` - Успешное завершение
- `/dashboard` - Дашборд пользователя
- `/admin` - Админ-панель с аналитикой и редактором
